\subsection{Model Size and Inference Efficiency}\label{sec:exp-efficiency}

With the gating and BCMS dimensions set to 32, RBSRN has approximately 7.071 million trainable parameters. We measured inference efficiency with the Chengdu checkpoint used in the main comparison. Each batch-size setting used one NVIDIA A100-SXM4-40GB GPU with FP32 tensors; the remaining environment is listed in Section~\ref{sec:exp-implementation}. Each window provides 12 historical flow steps and produces 12-step inflow and outflow forecasts for 1,024 nodes.

For batch size 1, we used compiled BCMS operators and CUDA Graph with 20 warm-up and 100 timed iterations. For batch size 64, we used 10 warm-up and 30 timed iterations. CUDA synchronization preceded and followed each measurement. We report the median and 95th percentile (P95).

Forward-only timing includes model computation on GPU-resident inputs and excludes input copying. End-to-end timing includes memory-resident data access, wavelet decomposition, normalization, state-evidence construction, CPU/GPU transfers, inference, inverse standardization, and returning results to the CPU, as well as input updates before CUDA Graph replay. Both measurements exclude startup preparation, offline graph construction, and cold disk reads.

Table~\ref{tab:inference-latency} reports median forward-only and end-to-end latencies of 15.907\,ms and 19.228\,ms for a single window, with an end-to-end P95 of 19.507\,ms. These measured computation times are below the 5-minute update interval. At batch size 64, the median end-to-end time was 1,280.394\,ms/batch and the amortized forward-only time was 17.794\,ms/window. Batch size 1 characterizes the response time of an individual request.

The inference configurations above used the same model checkpoint. We compared each against the reference implementation at the same batch size. At batch size 64, checking all 1,723 test windows yielded a maximum absolute prediction difference of \(7.63\times10^{-6}\). Batch size 1 passed a sampled check against the reference at the same batch size. Aggregate forecasting metrics were similar across the two batch sizes, although individual predictions were not identical. All main accuracy results were evaluated at batch size 64.
